# Rishi Mukherjee — Portfolio

A fast, accessible, zero-build personal portfolio for a Senior Analytics Engineer.

## Deploy

Compatible with GitHub Pages and Cloudflare Pages. No build command is required; publish from the repository root.

## Notes

- Vanilla HTML, CSS, and JavaScript; no framework or runtime dependencies.
- Theme preference is saved locally in the browser.
- Replace social/contact URLs and add a PDF resume when those assets are available.
